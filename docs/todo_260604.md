## Strava 카드 폰트 개선

### 현재 상황
- HTML 디자인(`strava_card_design.html`)은 **LINE Seed KR Bold (700)** 사용
  - 큰 숫자: `font-size: 96~108px; font-weight: 700; letter-spacing: -4px`
  - 묵직하고 응집감 있는 느낌
- 현재 SVG 카드: `DejaVu Sans` (Regular) + `NotoSansKR` (Regular) → 얇고 힘 없음
- resvg는 WOFF2 미지원 → TTF/OTF만 사용 가능 (LINE Seed 직접 못 씀)

### 폰트 후보 분석

#### 영문 전용 (가볍고 강렬, Latin only)
| 폰트 | 특징 | 용량 | 비고 |
|------|------|------|------|
| **Bebas Neue** | all-caps, 매우 condensed, 피트니스 앱 정석 | ~50KB | 숫자 최고, 영문 only |
| **Barlow Condensed ExtraBold** | 스포츠 느낌, 숫자 묵직 | ~80KB | 가장 추천 |
| **Anton** | Bebas 계열, 강렬한 임팩트 | ~40KB | 단일 weight |
| **Oswald Bold** | condensed bold, 가독성 좋음 | ~80KB | |

→ 영문 라벨로 전환 시 이쪽이 최선. 용량도 50~80KB로 가볍고, NotoSansKR 10MB 제거 가능

#### 한/영 통합 (Korean 지원)
| 폰트 | 특징 | 용량 | 비고 |
|------|------|------|------|
| **Black Han Sans** | 매우 굵고 강한 한글+영문, Google Font | ~2MB | TTF 있음, 단일 weight (Black) |
| **Noto Sans KR Bold** | 현재 파일(variable)에 bold weight 포함 | 이미 있음 | `font-weight: 700` 적용 필요한지 확인 |
| **IBM Plex Sans KR Bold** | 세련된 볼드, 한+영 | ~3MB | TTF 있음 |
