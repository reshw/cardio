**새 개념: `club_leagues` 테이블**
```
club_leagues
  - id, club_id
  - name          (예: "루키", "일반", "엘리트")
  - min_points    (예: 0, 100, 200)
  - max_points    (예: 99, 199, null = 무제한)
  - badge_text    (예: "루키", "⭐", "💎")
  - color         (예: "#4FC3F7")
  - display_order
```
