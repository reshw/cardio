> 작성일: 2026-05-25

## 배경 & 전략적 포지션

- 200명 부동산 업계 클럽 (금융·시공·신탁·시행). 유부남 직장인, 짬내서 운동.
- 철인3종 300마일 ↔ 저활동 50마일 격차 → 상위 10명 리그, 나머지 190명 구경꾼
- 팀전으로 "내가 팀에 기여했다"는 경험 → 하위권도 참여 동기 생김
- **장기 포지션**: 클럽 내 팀전 → 클럽 vs 클럽 대항전 → 리그 시스템으로 확장할 씨앗

## 확정 사항

### 형식
- **홍팀 / 백팀** 2팀 고정 (팀명은 관리자가 변경 가능)
- 경쟁 지표: **1인당 평균 마일리지** (팀원수 차이 자동 보정)
- 같은 클럽 내 대결 → 마일리지 계수 동일 → 직접 비교 가능

> 운동일수·달성률은 현 단계 사용 불가 (운동일수: 종목별 빈도 차이 / 달성률: 목표설정 시스템 선행 필요)

### 자동 팀 배정 알고리즘
1. 전달 마일리지 기준 전체 멤버를 **4구간** 분할
2. 각 구간 내에서 **랜덤**으로 절반씩 양 팀 배정
3. 팀 밸런스 보장 + 예측 불가 → 어뷰징 방지 (패턴 알면 전달에 일부러 덜 뛰는 문제)
4. 홀수 인원: 마지막 1명 랜덤 배정 (평균 지표라 영향 미미)

### 팀장
- 클럽 내 **분과장** (자전거·수영·트레일런 등)이 자연스러운 팀장감
- 관리자가 팀 구성 시 팀장 1명 지정
- 팀장이 팀원 독려하는 구조가 핵심 재미 (앱 기능보다 소셜 다이나믹)

### 타임라인
```
월초 1~3일  관리자 팀 구성 & 팀장 지정 & 공개
월중        팀별 실시간 순위 표시
월말 D-3    역전 알림
다음달 초   결과 발표, 우승팀 배지
```

## 이벤트 시스템으로 확장

챌린지는 이미 Club.tsx에 통합 완료 (있으면 표시, 없으면 숨김).  
홍백전을 챌린지와 같은 레벨의 **이벤트 타입** 으로 추가하는 구조.

```
이벤트
├── 챌린지형     개인 목표 달성 (기존 구현)
├── 팀대결형     홍백전 ← 신규
├── 릴레이형     클럽 합산 목표
├── 특수룰형     새벽 생존 등 시간대/조건 제한
└── 오프라인형   대회 원정, 분과 정모 (기록 남기는 용도)
```

### 월간 이벤트 캘린더 (안)
```
1월   신년 챌린지 — 개인 목표 공개 선언 & 월말 달성 여부 공개
2월   홍백전
3월   봄 대회 원정 — 봄 마라톤 시즌, 다함께 대회 참가
4월   분과 정모 — 자전거·수영·트레일런 분과 오프라인
5월   분과 정모 + 대회 참가 (기존 운영)
6월   클럽 릴레이 — 전체 합산 목표 마일리지 함께 채우기
7월   새벽 생존 챌린지 — 폭염 극복, 오전 6시 이전 기록만 인정
8월   수영의 달 — 수영 마일리지 별도 랭킹, 수영 분과 주도
9월   홍백전 시즌2 — 팀 재배치 설욕전
10월  가을 대회 원정 — 기록의 계절
11월  PB 달성 챌린지 — 종목별 개인 최고기록 경신 수 랭킹
12월  연말 생존왕 — 운동 1회 이상 기록한 날수만으로 경쟁
```

## 미결 사항

1. **팀 구성**: 자동 배정만? 관리자 수동 조정도 허용?
2. **보상**: 배지만? 소셜 포인트 연동?
3. **상시 vs 이벤트성**: 관리자가 원하는 달에만 열기 (권장) vs 매달 자동
