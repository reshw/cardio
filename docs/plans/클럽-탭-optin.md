# 클럽 탭 opt-in/out 설계

> 작성일: 2026-08-11
> 관련 문서: [클럽달력.md](클럽달력.md) — 이 탭이 첫 opt-in 대상
> 상태: 설계 초안, 구현 대기 (사용자 확인 후 진행)

---

## 1. 배경

클럽달력을 Club.tsx 탭으로 상시 노출했더니, 행사가 잦은 대형 클럽(200명·주 1회)과
소규모 클럽(20명·월 1회) 사이에 이 기능의 무게감이 다르다는 문제가 나옴 — 후자에겐
"달력 있는데 뭐 어쩌라고" 느낌의 노이즈. → **클럽별 opt-in 기능**으로 전환.

장기적으로 탭 편집(순서 변경 등) 가능성까지 염두에 두고 설계하되, 지금은 켜고 끄는
것만 한다 — YAGNI. 나중에 순서 편집이 필요해지면 그때 스키마를 한 번 더 확장한다.

---

## 2. 데이터 모델

```sql
ALTER TABLE public.clubs
  ADD COLUMN IF NOT EXISTS enabled_features text[] NOT NULL DEFAULT '{}';
```

- `text[]` 로 시작 — 순서 개념 없이 "켜져 있는 기능 키 목록"만. 신규/기존 클럽 전부 기본 `{}` (전부 OFF).
- 앱 코드에 기능 레지스트리 하나를 둔다 (신규 optional 기능 추가할 때마다 여기 한 줄만 추가):

```ts
// src/config/clubFeatures.ts (신규)
export const OPTIONAL_CLUB_FEATURES = [
  {
    key: 'calendar',
    label: '클럽달력',
    description: '행사 일정을 등록하고 사진으로 기록해요',
  },
  // 다음 opt-in 기능이 생기면 여기 추가
] as const;
```

- 나중에 탭 순서 편집까지 필요해지면 `text[]` → `jsonb`(순서 있는 배열)로 컬럼 하나만 바꾸면 됨 —
  지금 설계가 그걸 막지 않음.

## 3. UX 플로우

### 위치: 클럽 설정 › "탭 관리" 섹션 (신규)

`ClubGeneralSettings.tsx` 안에 새 섹션 하나 추가. 지금은 항목이 1개뿐이지만,
**처음부터 리스트 형태로 만들어서** 다음 opt-in 기능이 생겨도 UI 구조를 안 건드리게 한다.

```
탭 관리
┌────────────────────────────────┐
│ 🗓️ 클럽달력                [○] │   ← Switch, 기본 꺼짐
│ 행사 일정을 등록하고 사진으로     │
│ 기록해요                         │
└────────────────────────────────┘
```

- 방장/부방장만 접근 가능 (기존 `ClubGeneralSettings` 권한 체크 그대로 재사용)
- 토글 즉시 저장 (별도 "저장" 버튼 없음 — 다른 스위치형 설정과 동일 패턴이면 그걸 따름, 확인 필요)
- 토글 ON → 탭바에 "클럽달력" 즉시 나타남 (리로드 불필요, `selectedClub` state 갱신만)
- 토글 OFF → 탭 사라짐. 사용자가 그 탭을 보고 있었다면 기본 탭(마일리지)으로 전환
- 멤버(비방장)는 이 스위치를 볼 수 없음 — 클럽달력이 꺼져 있으면 탭 자체가 안 보이는 것으로 충분,
  "이 기능이 존재한다"는 걸 굳이 알릴 필요 없음

### 빈 상태는 이미 처리돼 있음

토글을 켠 직후 행사가 0건이어도 기존 empty state("등록된 행사가 없습니다. + 행사 등록으로
첫 행사를 만들어보세요.")가 그대로 안내 역할을 함 — 별도 온보딩 UI 불필요.

---

## 4. 구현 순서

1. 마이그레이션: `clubs.enabled_features` 컬럼 추가
2. `clubService.ts` — `Club` 타입에 `enabled_features` 추가, `updateEnabledFeatures(clubId, features)` 추가
3. `src/config/clubFeatures.ts` — 기능 레지스트리 (2절)
4. `Club.tsx` — 탭 버튼 렌더링을 `selectedClub.enabled_features.includes('calendar')` 조건으로 감쌈
5. `ClubGeneralSettings.tsx` — "탭 관리" 섹션 + 스위치 UI

---

## 5. 미결 사항 (진행 전 확인 필요)

1. 토글이 즉시 저장인지, 다른 설정처럼 "저장" 버튼 누를 때 반영인지 — `ClubGeneralSettings.tsx` 기존 패턴 확인 필요
2. 기존에 이미 클럽달력을 써본 클럽(이번 세션에 테스트한 클럽 포함)도 기본 OFF로 리셋할지,
   아니면 이미 행사가 1건이라도 있으면 자동으로 ON 시켜줄지 — 데이터 있는데 탭이 사라지면 당황할 수 있음
