# 클럽달력 날짜 시트 — 탭 구조 개편 (운동 / 행사)

> 2026-10-07 요청: 클럽달력에서 날짜를 눌렀을 때 뜨는 바텀시트를 탭 형태로.
> 그날의 **운동**도 보고, **행사 목록·행사 상세**도 봐야 한다.
> 선행 작업: [club-workout-calendar.md](club-workout-calendar.md)

---

## 1. 지금 무엇이 문제인가

현재 날짜 시트(`DayWorkoutFeedSheet`)는 **운동 피드가 주인공이고 행사는 상단 칩으로 얹혀 있다.**

```
┌ 운동 기록 ─────────── ✕ ┐
│ [🏃 정기런] [🍻 번개]     │ ← 행사 칩 (누르면 행사 상세 시트가 또 뜸)
│ ‹  9월 4일  ›  오늘       │ ← 날짜 이동 (WorkoutFeed 내부)
│ 운동 카드 ×59 ...         │
└──────────────────────────┘
```

1. **행사가 칩 하나로 축소돼 있다.** 시간·장소·참가 인원 같은 정보가 안 보이고, 예전 날짜
   패널("M월 D일 행사" 목록)이 있던 자리를 잃었다.
2. **시트가 4겹까지 쌓인다.** 날짜 시트 → 행사 상세 시트 → 참가 승인/수정 시트 → 사진
   라이트박스. 이 앱은 "3중 이상 중첩 시트에서 엉뚱한 시트까지 닫히는" 버그를 고친
   이력이 있다(커밋 20b1b12). 겹을 줄이는 게 안전하다.
3. **날짜 이동이 `WorkoutFeed` 안에 들어 있다.** 탭을 나누면 운동 탭에서만 날짜가 바뀌고
   행사 탭은 그대로인 어긋남이 생긴다.
4. 날짜 이동이 **오늘까지만** 된다(운동 피드 기준). 그런데 행사는 미래 날짜에 있다.

## 2. 개선안

```
┌ 9월 4일 (금) ──────── ✕ ┐  ← 헤더(2-1 패턴). 제목 = 날짜
│ ‹          ›     오늘    │  ← 날짜 이동: 시트 레벨로 올림. 두 탭 공통
│ ┌────────┬────────┐     │
│ │ 운동 59 │ 행사 1  │     │  ← 탭 (기존 ranking-filter-tabs 재사용)
│ └────────┴────────┘     │
│                          │
│  (선택된 탭 내용)          │
└──────────────────────────┘
```

### 2-1. 날짜 이동 — 시트 레벨, 두 탭 공통

- 날짜 이동 줄을 `FeedDateNav` 컴포넌트로 분리한다 (이전 `WorkoutFeed` 안의 마크업 + 달력 피커 + 다음 버튼
  `maxDate` 처리가 한 덩어리였다). `WorkoutFeed` 는 `showDateNav` prop(기본 true)으로 끄고, 시트가
  같은 `FeedDateNav` 를 상단에 둔다. 오늘운동 탭은 영향 없음
- 날짜를 바꾸면 두 탭이 같이 바뀐다
- **행사 기능이 켜진 클럽은 미래 날짜로도 이동 가능** (다가오는 행사를 봐야 하므로).
  꺼진 클럽은 지금처럼 오늘까지
- 헤더 제목은 날짜(`9월 4일 (목)`). 사람·종목 필터가 걸려 있으면 운동 탭 안에 표시(§2-3)

### 2-2. 탭 — `운동 N` / `행사 M`

- 탭 라벨에 그날 건수를 붙인다. 눌러보기 전에 어디에 뭐가 있는지 보인다
- **행사 기능이 꺼진 클럽은 탭 바를 숨긴다** → 지금처럼 운동만 (opt-out 존중)
- **행사가 0건인 클럽에서 운영진이 아니면 탭 바를 숨긴다** — 일반 멤버에게 `행사 0` 은 소음
- **처음 열릴 때 기본 탭**: 그날 행사가 있으면 `행사`, 없으면 `운동` (확정)
- 날짜를 옮기면 기본 탭 규칙을 다시 적용하지 않는다 — 사용자가 고른 탭을 유지

### 2-3. 운동 탭

- 지금의 `WorkoutFeed` 그대로 (좋아요·댓글·차단 등)
- 달력에 걸린 **사람·종목 필터가 이 탭에만** 적용된다. 탭 상단에 `야시 · 달리기 필터 중`
  한 줄 표시 — 숫자가 왜 적은지 바로 알 수 있게
- 행사는 사람·종목 체계가 없으므로 행사 탭에는 필터를 걸지 않는다

### 2-4. 행사 탭 — 목록 → 상세를 **시트 안에서** 전환 (겹 줄이기)

- 행사 2건 이상: 목록(아이콘·제목·시간·참가 인원) → 누르면 **같은 시트 안에서** 상세로 전환,
  상단에 `‹ 목록` 버튼
- 행사 1건: 목록을 건너뛰고 **바로 상세**
- 행사 0건: `이 날은 행사가 없습니다.` + (운영진만) **`이 날짜로 행사 등록`** 버튼 →
  `CreateEventSheet` 가 눌렀던 날짜로 미리 채워져 열린다 (`initialDate` prop 추가, 한 줄)
- 미래 날짜의 운동 탭은 요청 없이 `아직 오지 않은 날이에요.` 를 보여준다
- 안드로이드 뒤로가기: 상세에서 누르면 **목록으로**, 목록에서 누르면 시트 닫힘.
  `useModalHistory` 를 상세 단계에 한 번 더 걸되(목록→상세일 때만 활성), **상세에서 ✕/배경으로 시트를
  통째로 닫을 땐 상세 엔트리를 먼저 `history.back()` 으로 pop 한 뒤 닫는다.** 두 훅이 동시에 정리되면
  시트 쪽 엔트리가 남아 뒤로가기를 한 번 더 눌러야 하는 유령 엔트리가 생긴다 (실측으로 `history.length`/
  `history.state` 가 원래대로 돌아오는 것 확인)

### 2-5. 행사 상세 재사용 방식 — 본문/껍데기 분리

`EventDetailSheet`(366줄)를 둘로 나눈다:

| | 역할 | 쓰는 곳 |
|---|---|---|
| `EventDetailContent` (신규) | 본문 + 그 안의 수정/승인/라이트박스/확인창 | 날짜 시트 행사 탭, 아래 시트 |
| `EventDetailSheet` (기존) | 오버레이·핸들·헤더 껍데기 + `EventDetailContent` | 클럽달력 상단 "다가오는 행사" 카드 |

로직 복제 없이 두 곳이 같은 상세를 쓴다. 날짜 시트 경로는 시트 1겹이 줄어 최대 3겹
(날짜 시트 → 승인/수정 → 라이트박스)이 된다.

### 2-6. 탭·날짜 줄 상단 고정 (sticky)

운동이 59건인 날, 아래로 내린 뒤 행사 탭으로 가려면 맨 위까지 올라가야 한다.
날짜 이동 줄과 탭 바를 헤더 아래에 **고정**한다.

> ⚠️ 바텀시트 가이드 §4 — sticky 기준선은 content box 라 `top`·덮개 계산을 시트 변수
> (`--sheet-pad-top`, `--sheet-gap`)로 해야 틈이 안 생긴다. 구현 후 가이드 §4-4 실측
> 스크립트로 "스크롤해도 안 움직이는지 + 위로 본문이 안 비치는지" 검증한다.

## 4. 결정 사항

1. **기본 탭** — 그날 행사가 있으면 `행사`, 없으면 `운동` (2026-10-07 확정)
2. **고정 영역(sticky) 높이** — 날짜 줄 + 탭 바는 헤더 바로 아래에 붙는다. 헤더 높이를 `--day-sheet-header-h`
   (48px) 변수로 두고 `top: calc(8px + var(--sheet-gap) + var(--day-sheet-header-h))` 로 계산한다.
   헤더 높이(32px 닫기 버튼 + 하단 padding 16px)를 바꾸면 이 변수도 같이 바꿀 것. 실측: 스크롤해도
   핸들·헤더 위치 불변, 헤더 바닥과 고정 영역 사이 간격 0

페이지 전체 개편은 [club-calendar-page-upgrade.md](club-calendar-page-upgrade.md) — 이 문서는 그 §3-4 다.
