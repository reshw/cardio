# Cardio App v2.0 — 확정 스코프 & 전파 전략

> 이 문서는 v2.0 기획의 최종 구현 범위와 운영진 전파 순서를 정리한 것.
> 전체를 한 번에 공개하지 않고 단계별로 유도하는 전략을 포함.

---

## 확정 기능 스코프 (1차)

### 1. 루키 리그
- **대상**: 생애 월 누적 마일리지 [100]마일 미달성자
- **구현**: 클럽 랭킹 내 필터/정렬 분리 (별도 탭 또는 토글)
- **졸업 조건**: 생애 첫 100마일 달성 순간 자동 편입
- **포상 없음**: 루키 리그 내 순위 시상 없음. 졸업시 포상.

### 2. 소셜 포인트

| 항목 | 점수 | 검증 |
|------|------|------|
| 카톡 기록 공유 | +1점 / 일 1회 | 버튼 클릭 자동 |
| 신규 회원 앱 초대후 20마일 활성화 | +5점 | 마일리지 달성 시 자동 |
| 운영진 및 분과장 과 운동 후 사진찍기 | +10점 / 운영진 1인당 | 운영진 직접 승인 |

- (운영진 4명 + 분과장 n 명) × 10점 = 월 최대 ??? 점 (번개에 운영진 모두 끌어낸 사람이 소셜 1위)


### 3. 소셜 포디움
- 클럽 탭 내 마일리지 랭킹 옆 **소셜 포인트 랭킹** 탭 추가
- 월별 초기화, 이달의 소셜 챔피언 기록 보존

### 4. 월말 시상 구조

| 시상 | 기준 | 비고 |
|------|------|------|
| 🥇 마일리지 1위 | 당월 마일리지 합산 | 현행 유지 | 
| 🤝 이달의 커넥터 | 소셜 포인트 1위 | 운영진 추천 슬롯 → 객관적 기준으로 대체 |
| 🎓 졸업자 | 해당월 졸업 달성자 전원 | 신규 추가 |

### 5. 졸업 시스템

| 단계 | 조건 | 성격 |
|------|------|------|
| 🏫 초등학교 졸업 | 생애 누적 100마일 최초 달성 | 지속성 |
| 🏫 중학교 졸업 | 10km 60분 이내 기록 1회 | 퍼포먼스 |

- 달성 시 클럽 피드 자동 공지 + 프로필 영구 뱃지
- 고등학교 이상은 커뮤니티 반응 보고 추후 추가

### 6. 전달 대비 성장률 대시보드 (운영진용)
- 운영진(manager/vice-manager)만 접근 가능
- 전체 회원 전달 마일리지 vs 이번달 마일리지 비교
- 성장률(%) 표시, 컬럼 기준 정렬 가능
- 용도: 운영진 추천 시상 근거 자료, 케어 대상자 파악

## 운영진 전파 전략 (단계별 유도)

전체를 한 번에 쏟아내지 않는다. 운영진이 문제를 먼저 말하게 만드는 순서.

### 1단계 — 현재: 루키 리그만
숙제 하나만 완성. 발표 시 한 마디 끼워넣기.
> *"루키 분들이 다음 달에도 있게 하려면 뭔가 붙잡을 게 있어야 할 것 같긴 한데, 일단 해보겠습니다."*

### 2단계 — 1개월 후: 데이터로 문제 제기
직접 제안 없이 관찰 보고 형식.
> *"루키 중에 2주 안에 로그인이 없는 분들이 보이는데요. 뭔가 붙잡아주는 게 있으면 좋겠다는 생각이 드는데, 대장님은 어떻게 생각하세요?"*

### 3단계 — 운영진이 "그럼 어떻게?" 하면: 소셜 포인트 경량판
카톡 공유 + 번개 2가지만 먼저. 전체 시스템 언급 없음.
> *"번개 나오면 +5점, 기록 공유하면 +1점 이렇게 두 가지만 일단 해보시죠. 한 달 보고 반응 보면서 더할지 결정하면 어떨까요."*

### 4단계 — 분위기 뜨거울 때: 운영진 소환권
대장님 본인 이야기라 수용이 쉬움.
> *"대장님이 나가실수록 방이 더 뜨거워지는 구조를 넣을게요. 대장님 모시고 나온 사람한테 특급 점수요."*

### 5단계 — 소셜 3개월 후: 성장률 대시보드 + 졸업 시상
> *"운영진 추천 시상 근거가 생겼습니다. 소셜 포인트 1위 + 성장률 대시보드 보고 뽑으시면 됩니다."*

### 6단계 — 보증금 시스템은 맨 마지막
가장 민감. 커뮤니티가 충분히 달아오른 후에만 꺼냄.

## 전략 원칙

| 원칙 | 행동 |
|------|------|
| 숙제 하나씩 | 이전 것 완성 전까지 다음 얘기 없음 |
| 답 전에 질문 | 운영진 입에서 먼저 나오게 |
| 데이터로 말하기 | 의견이 아닌 숫자로 문제 제기 |
| 대장님 주인공화 | 내가 만든 시스템이 아니라 대장님 아이디어처럼 |
| 보증금은 마지막 | 3개월 이상 소셜 활성화 후에만 |
