## 개념

운동 마일리지와 **완전히 별개**의 포인트 트랙.  
"얼마나 뛰었나"가 아닌 "얼마나 커뮤니티에 기여했나"를 측정.

---

## 획득 루트

| 행동 | 점수 | 집계 방식 | 제한 |
|------|------|----------|------|
| 카톡 기록 공유 | +1 | 앱 내 공유 버튼 자동 | 하루 1회 |
| 카페 글 작성 | +n | 자동 검토 필요 (↓) | - |
| 대회 인증 (3인 이상) | +3 | 사진 제출 + 운영진 승인 | - |
| 신규회원 초대 | +n | 추천인 입력 → 당월 활성화 시 자동 | 먹튀 방지 |
| LSD / 인터벌훈련 참가 | +n | 운영진 직접 입력 | - |
| 기부금 납입 | +1/만원 | 운영진 수동 지급 | - |

## UI 구조 — 안 B (확정)

### 상위 탭 재편

```
현재:  🏆 마일리지  |  🏃 오늘의 운동
변경:  🏃 오늘의 운동  |  🏆 마일리지  |  🤝 소셜
```

- 탭 순서: 오늘의운동(기본) → 마일리지 → 소셜
- 기본 탭은 기존과 동일하게 `feed` 유지

### 소셜 탭 내부 구조

```
[내순위]  [전체]          ← ranking-filter-tabs 스타일 그대로 재사용

──── 내순위 뷰 ────
┌─────────────────────────┐
│  이번 달 소셜 포인트      │
│  🤝 12점   클럽 3위      │
└─────────────────────────┘

📤 기록 공유    +1   05.26
🏅 대회 인증    +3   05.20
📤 기록 공유    +1   05.19
...

──── 전체 뷰 ────
1위  홍길동   18점  👑
2위  김철수   15점
3위  나석환   12점  ← 본인 하이라이트
...
```

## DB 설계

```sql
social_points (
  id          uuid primary key default gen_random_uuid(),
  club_id     uuid references clubs(id),
  user_id     uuid references users(id),
  points      int not null,
  action_type text not null,  -- 'share' | 'cafe_post' | 'race' | 'referral' | 'training' | 'donation'
  description text,
  ref_id      uuid,           -- 연관 workout_id, 대회 id 등
  approved_by uuid,           -- 수동 승인자
  created_at  timestamptz default now(),
  year        int not null,
  month       int not null
)
```

월별 합산: `year + month` 기준 집계.  
중복 방지 (share 하루 1회): `date_trunc('day', created_at) + user_id + action_type` 체크.
