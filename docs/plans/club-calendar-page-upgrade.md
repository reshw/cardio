# 클럽달력 페이지 개편

> 2026-10-07 요청: "오늘의 행사가 맨 위여야 할 것 같고, 클럽달력 페이지 자체의 경험이 너무 약함."
> 날짜를 눌렀을 때의 시트 개편은 [club-calendar-day-sheet.md](club-calendar-day-sheet.md) — 이 문서의
> §3-4 로 포함된다. (기본 탭: **그날 행사가 있으면 `행사`, 없으면 `운동`** — 확정)

---

## 1. 실측 — 이 페이지는 실제로 어떻게 쓰이고 있나

### 행사 (2026-10-07 기준)

| 클럽 | 행사 | 예정 | 지난 | 사진 | **참가 체크인** |
|---|---|---|---|---|---|
| 유산소의 모든것 | 19 | 2 | 17 | 55 | **0** |
| 아런 | 4 | 0 | 4 | 4 | **0** |
| 우미 런 | 2 | 0 | 2 | 4 | **0** |
| 나머지 11개 클럽 | 0 | | | | |

"유산소의 모든것" 최근 행사: `JTBC마라톤` · `춘천마라톤` · `구례 아이언맨` · `수영 정모` · `월간 정기훈련
인터벌` · `성남트레일레이스` · `한강 플로깅` · `수영 번개` …

여기서 나오는 결론 세 가지:

1. **행사는 "참가 신청"이 아니라 "일정 공유 + 사진 기록"으로 쓰인다.** 체크인은 전 클럽 0건,
   사진은 63장. 지금 화면은 참가 흐름 중심으로 짜여 있는데 아무도 안 쓴다.
2. **행사 대부분이 마라톤 대회·정모·번개** — 몇 주 전부터 잡아두는 일정이다. "며칠 남았나"가
   의미 있는 정보다. 시각은 거의 전부 `00:00`(종일)이고 실제 시각·장소는 메모에 적는다.
3. **14개 클럽 중 11개는 행사가 0건이다.** 이 클럽들에게 클럽달력 = 운동 갯수 달력이다.
   행사가 없을 때 페이지가 비어 보이면 안 된다.

### 지금 화면 구성

```
[+ 행사 등록]            ← 운영진만, 우측 상단 알약 버튼
다가오는 행사 (최대 2개)  ← 오늘 행사도 여기 섞여 있음
[사람] [종목]
┌ 달력 (칸마다 운동 갯수, 행사 있는 날은 5px 점) ┐
```

### 문제

| # | 문제 | 왜 약한가 |
|---|---|---|
| 1 | **"오늘"이 없다** | 오늘 행사가 다가오는 행사 목록에 섞여 묻힌다. 페이지에 기준점이 없다 |
| 2 | 다가오는 행사가 **최대 2개, 더보기 없음** | 3번째 일정부터는 달력을 넘겨 찾아야 한다. 며칠 남았는지도 안 보인다 |
| 3 | 달력에서 행사가 **5px 점** | 운동 숫자 옆에서 거의 안 보인다. 무슨 행사인지 모른다 |
| 4 | **지난 행사·사진에 갈 길이 없다** | 가장 많이 쓰인 자산(사진 63장)이 달력을 한 달씩 넘겨 날짜를 눌러야만 보인다 |
| 5 | 날짜 시트에서 행사가 칩 하나 | → [club-calendar-day-sheet.md](club-calendar-day-sheet.md) |

## 2. 개편 후 구성

```
┌───────────────────────────────────────┐
│ 오늘 · 10월 25일 (일)                    │  ← ① 오늘 카드 (항상 맨 위)
│ 🏃 춘천마라톤(26년)                       │     오늘 행사 있으면 행사,
│ 마라톤 · 메모 첫 줄…            사진 3 › │     없으면 오늘 운동 요약 한 줄
├───────────────────────────────────────┤
│ 다가오는 행사                  + 등록     │  ← ② D-day 리스트 (3개 + 더보기)
│ D-7   🏃 JTBC마라톤('26년)   11/1(일)   │     등록 버튼은 섹션 헤더로 이동
│ D-14  🏊 수영 정모            11/8(일)   │
│                          더보기 (2)      │
├───────────────────────────────────────┤
│ [사람] [종목]                            │  ← ③ 운동 달력
│ ┌ 10월 ─────────────────────────────┐ │     행사 있는 날은 점 대신 아이콘
│ │  1🏃   2    3    4 ...             │ │
│ │  43   42   43   54                 │ │
│ └────────────────────────────────────┘ │
├───────────────────────────────────────┤
│ 지난 행사                                │  ← ④ 사진 있는 지난 행사
│ [📷][📷][📷]  교대인터벌 · 9/3 · 사진 8   │
│ [📷]         …                 더보기 ›  │
└───────────────────────────────────────┘
```

**행사가 0건인 클럽(11곳)**: ②④ 섹션은 통째로 숨긴다. ①은 오늘 운동 요약으로, ③은 그대로.
운영진에게만 ② 자리에 얇은 `+ 첫 행사 등록` 안내 한 줄.

**행사 기능을 끈 클럽**: ②④ 숨김, ①은 운동 요약만, 날짜 시트는 탭 없이 운동만.

## 3. 섹션별 상세

### 3-1. ① 오늘 카드

- **오늘 행사가 있으면** 행사 카드: 아이콘 · 제목 · 종목(category_text) · 메모 첫 줄 · 사진 수.
  누르면 날짜 시트가 **오늘 날짜 · 행사 탭**으로 열린다. 오늘 행사가 2개 이상이면 첫 번째를
  크게, 나머지는 `+1건` 표시
- **오늘 행사가 없으면** 한 줄 요약: `오늘 클럽원 43회 운동했어요 ›` — 누르면 날짜 시트 **운동 탭**.
  운동 갯수만이고 거리·마일리지 같은 양 총합은 넣지 않는다 (앞선 결정과 동일)
- 이 숫자는 달력의 `dayCounts` 를 재사용하지 **않는다** — 그건 사람·종목 필터와 보고 있는 달에 묶여
  있어서 필터를 걸거나 달을 넘기면 오늘 숫자가 바뀐다. 필터 없는 이번 달 `getWorkoutDayCounts` 를
  따로 한 번 더 부른다
- 메모 첫 줄은 "값이 채워진" 첫 줄만 쓴다. 양식(`1. 일시: ` …)만 있고 비어 있으면 생략
- 시각은 표시하지 않는다 — 행사가 거의 전부 `00:00`(종일)이라 "오전 12:00"이 찍히면 오해를 산다

### 3-2. ② 다가오는 행사 — D-day 리스트

- 오늘 이후 행사만 (오늘 것은 ①로 올라갔으므로 중복 제외)
- 왼쪽에 **D-day 배지**(`D-7`), 오른쪽에 날짜. 마라톤 대회처럼 미리 잡는 일정에 맞다
- 3개까지 보이고, 넘으면 같은 자리에서 펼치는 `더보기 (N)` (접기 포함). 별도 `UpcomingEventsSheet` 는
  만들지 않는다 — 가장 많은 클럽도 예정 행사가 2건이라 "전체 보기"가 뜰 일이 없고, 새 시트 층만 늘어난다
- `+ 행사 등록` 버튼을 페이지 우상단 알약에서 **이 섹션 헤더 오른쪽**으로 옮긴다 —
  행사와 관련된 동작이 행사 옆에 있게

### 3-3. ③ 운동 달력

- 지금 그대로 (칸마다 운동 갯수, 사람·종목 필터)
- 행사 있는 날: 5px 점 → **행사 종류 아이콘**(🏃/🏊 등 `EVENT_TYPE_ICONS`)을 칸 우상단에 작게.
  같은 날 여러 개면 첫 번째 아이콘만
- 오늘 칸은 기존 강조(분홍 테두리) 유지

### 3-4. 날짜 시트 — 탭 구조

[club-calendar-day-sheet.md](club-calendar-day-sheet.md) 그대로:
날짜 이동을 시트 상단으로 올려 두 탭 공통 / `운동 N` · `행사 M` 탭 / 행사 목록→상세를 시트 안에서
전환(시트 4겹 → 3겹) / 0건이면 운영진에게 `이 날짜로 행사 등록` / 날짜 줄·탭 상단 고정.

### 3-5. ④ 지난 행사

- **사진이 있는 지난 행사**를 최신순으로 (사진 없는 지난 행사까지 다 늘어놓으면 목록이 길어지고
  볼 게 없다 — 지난 행사 전체는 달력에서 날짜를 누르면 어차피 보인다)
- 행사마다 대표 사진 1장(가장 먼저 올라온 것) + 제목 · 날짜 · 사진 수
- 최근 3건 + 같은 자리에서 펼치는 `더보기 (N)`
- 누르면 행사 상세 (사진 라이트박스로 바로 넘겨보기)
- 데이터: `club_event_photos` 에서 행사별 첫 사진 + 장수만 가져오는 조회를 서비스에 추가
  (지금 `listEvents` 는 사진을 안 가져온다). DB 변경 없음

## 4. 단계

| 단계 | 내용 | 비고 |
|---|---|---|
| **1단계** | ① 오늘 카드 · ② D-day 리스트(더보기, 등록 버튼 이동) · ③ 달력 행사 아이콘 · 날짜 시트 탭화 · **행사별 사진 수·대표 사진 조회** | 사용자가 지적한 "오늘이 맨 위" + 시트 개편. 오늘 카드의 "사진 N" 때문에 사진 조회가 1단계에 필요하다 |
| 2단계 | ④ 지난 행사 사진 앨범 | 1단계에서 만든 사진 조회를 그대로 쓰므로 같이 구현했다 |

DB 변경 없음. 바뀐 파일은 날짜 시트 문서 §3 + `ClubCalendarTab.tsx` 재구성 + 신규
`ClubCalendarToday`(①) / `ClubEventLists`(② `UpcomingEventsSection`, ④ `PastEventsSection`).
서비스에는 `listEventPhotoSummaries`(행사 ID별 사진 수 + 대표 사진) 하나만 추가했다.

## 5. 이번에 안 하는 것 (후속 아이디어)

- **참가 체크인 재설계** — 0건이라는 건 지금 흐름이 안 맞는다는 뜻이다. 예: 행사 날 해당 종목으로
  운동을 기록한 사람을 "참가자 후보"로 자동 제안. 범위가 커서 별도로 다룬다
- 행사 리마인드 알림(D-1 푸시) — 팔로우 알림과 같이 "알림 종류별 on/off" 가 선행돼야 한다
  ([club-workout-calendar.md](club-workout-calendar.md) §6)

## 6. 구현하며 확정한 것 (2026-10-07)

- **행사 0건 클럽의 날짜 시트**: 운영진이 아니면 `행사 0` 탭 바를 숨긴다. 일반 멤버에게는 늘 비어 있는
  소음이고, 운영진만 `이 날짜로 행사 등록` 진입점으로 남긴다
- **② 섹션 노출 조건**: 예정 행사가 있거나, 운영진일 때. 운영진에게는 행사가 없어도 헤더 + `+ 등록` +
  빈 상태 문구(행사가 아예 없으면 "첫 행사를 등록해 보세요")를 보여준다
- **달력 칸 아이콘**: 같은 날 여러 개면 첫 번째만. 예전 5px 점(`.has-event::after`)은 제거
- 행사를 다시 불러올 때(사진·수정 직후)는 로딩 표시를 켜지 않는다 — 섹션이 깜빡이며 사라지지 않게
- 사진 추가/삭제도 `onChanged` 로 부모에 알려, 오늘 카드의 사진 수·지난 행사 앨범이 바로 갱신된다
