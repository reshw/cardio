# [작업지시서] 자릿수 연동형 하이브리드 휠 피커 (Wheel Picker) 구현

## 1. 개요 (Overview)
- 목적: 자릿수 선택(<, >)과 값 증감(+, -)의 인지적 불일치를 해결하기 위한 직관적인 수치 선택 UI 구현.
- 핵심 콘셉트: 활성화된(Focused) 자릿수 박스를 기준으로 증감(+, -) 버튼이 위아래에 세트로 묶여 함께 이동하는 하드웨어 다이얼 스타일의 하이브리드 UI.
- 타겟 컴포넌트: 총 6개의 독립적인 목표 설정 행(Row)으로 구성.

---

## 2. UI/UX 디자인 요구사항 (UI/UX Specifications)

### A. 레이아웃 및 컴포넌트 구조
- 전체 화면 중앙에 카드 형태(`max-width: 520px`)로 배치.
- 총 6개의 세로 정렬된 행(`picker-row`)으로 구성.
- 각 행의 구성: `[항목명 (예: 목표 1)]` + `[컨트롤 영역]` + `[단위 (km)]`

### B. 컨트롤 영역 구조 (핵심)
- **좌우 이동 버튼:** `<` (좌측 끝), `>` (우측 끝)에 배치.
- **자릿수 그룹:** 백의 자리 / 십의 자리 / 일의 자리 (총 3개 자릿수 박스 고정).
- **증감 버튼 매칭:** - 각 자릿수 박스는 상단에 `+`, 하단에 `-` 버튼을 수직으로 가짐.
  - **[중요]** 현재 활성화된(`active`) 자릿수만 위아래 `+`, `-` 버튼이 시각적으로 노출되어야 하며, 비활성화된 자릿수의 버튼은 숨김 처리 (`opacity: 0` 및 마우스 인터랙션 차단).

### C. 시각적 스타일 가이드 (CSS)
- **비활성 자릿수:** 연한 회색 텍스트(`#94a3b8`), 배경색 없음.
- **활성(`active`) 자릿수:** 연한 블루 계열 배경 테두리 박스 처리, 메인 포인트 컬러 텍스트 적용으로 명확한 포커싱 연출.
- **증감 버튼 위치:** 자릿수 박스의 상대 좌표(`position: absolute`)를 활용하여 숫자의 위아래 정렬 붕괴 없이 칼같이 정렬 유지.

---

## 3. 기능 요구사항 (Functional Requirements - JavaScript)

### A. 자릿수 네비게이션 (좌우 이동)
- `<` 버튼 클릭 시: 포커스(`active` 클래스)가 왼쪽 자릿수로 이동. (백의 자리에서 멈춤)
- `>` 버튼 클릭 시: 포커스(`active` 클래스)가 오른쪽 자릿수로 이동. (일의 자리에서 멈춤)
- 초기 디폴트 활성화 자릿수: **십의 자리**

### B. 값 증감 및 롱프레스 (Long-press) 로직
- 활성화된 자릿수의 `+`, `-` 버튼을 누르면 해당 자릿수의 숫자가 `0 ~ 9` 사이에서 순환하거나 자릿수 올림/내림 처리 (기획에 맞게 택1, 기본은 해당 자리 숫자 0~9 가감).
- **롱프레스 인터랙션:** `+` 또는 `-` 버튼을 1초(1000ms) 이상 누르고 있을 경우, 누르고 있는 동안 0.1초(100ms) 간격으로 값이 1씩 연속해서 증가/감소하는 타이머 로직 구현. (마우스 마우스업/리브 시 타이머 해제)

### C. 하단 직접 입력
- 하단에 "직접 입력하기" 버튼 배치.
- (추후 확장성 고려) 혹은 자릿수 숫자 자체를 더블클릭/클릭 시 `input type="number"` 포커싱으로 전환되는 구조를 처리할 수 있도록 마크업 설계.

---

## 4. 최종 결과물 양식 (Deliverables)
- HTML5 표준 마크업 유효성 준수.
- CSS3 Flexbox 및 Grid, CSS 변수(`:root`)를 활용한 모던하고 정돈된 스타일링.
- 외부 라이브러리(jQuery 등) 없이 순수 Vanilla JS로 독립적 작동 가능한 단일 파일(.html) 또는 컴포넌트 코드로 작성할 것.
