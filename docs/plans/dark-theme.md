# 다크 테마 도입 + 색상 토큰화

- 발단: 사용자 요청("테마/색깔 바꾸기 기능"). 자유 컬러피커 대신 **검증된 다크 테마 1종**으로 스코프 확정.
- 결정: **브랜드색 유지 + 밝기만 올림** (앱 정체성 유지, 라이트↔다크 전환이 자연스러움)
- 결정: **사용자 화면 우선, 어드민 페이지는 보류**

## 왜 컬러피커가 아니라 다크 테마 1종인가

- `--primary-color`가 배경색·글자색 양쪽으로 쓰여서, 자유 색상 선택을 열면 밝은 색 고른 사용자는
  버튼 글씨가 안 보이는 대비 사고가 남. 프리셋/고정 테마는 미리 검증해서 그 리스크가 사라짐
- 설정 UI가 토글 하나로 끝남 (기존 [More.tsx](../../src/pages/More.tsx) "앱 설정" 섹션의 `toggle-switch` 재사용)
- `data-theme` 인프라가 생기면 이후 테마 추가·시스템 다크모드 자동감지가 전부 이 위에서 감

## 신규 토큰 (구조색 치환용)

기존 토큰만으로는 부족해서 추가 — 하드코딩된 자리를 이걸로 바꾼다.

- `--body-bg` — body 배경 그라데이션 (라이트: 흰→하늘→핑크, 다크: 딥네이비 단색계)
- `--surface-translucent` — 헤더/바텀네비의 `rgba(255,255,255,0.98)` 자리
- `--surface-elevated` — 컬러 배경 위에 뜨는 흰 카드
- `--scrim` — 모달 backdrop (두 테마 공통 `rgba(0,0,0,.5)` 계열이나 다크는 더 진하게)
- `--on-accent` — primary/secondary 배경 위에 얹는 글자색

### 작업 중 발견해 같이 고친 것

- **대비 사고 46곳**: `--primary-color` 배경 + 흰 글자 조합. 다크에서 primary 가 밝은 시안(`#5DD6FF`)이
  되므로 흰 글자는 판독 불가 → `--on-accent` 로 치환
- **아바타 10종**: 배경은 인라인(브랜드 그라데이션), 글자색은 CSS 라 위 일괄 치환이 놓쳤음.
  실측 대비 **1.68:1** (WCAG 최소 4.5:1 미달) → `--on-accent` 적용 후 **11.27:1**
- **명예의전당 카드**: 불투명 파스텔 금색이 다크에서 눈부심. 코드베이스에 이미 있던
  `.hall-of-fame` 의 "반투명 금색 + 금색 테두리" 패턴으로 통일
- **랭킹 행 강조**: [Club.tsx](../../src/pages/Club.tsx) 에 인라인 그라데이션으로 박혀 있어
  CSS 만 고쳐선 안 바뀜 → 인라인도 토큰으로 교체
- **hover 흰색 튐**: `.menu-item-btn:hover` 등 밝은 회색 하드코딩 6곳
- **입력창 focus 흰 배경** 5곳
