## 이슈 2: 마일리지 탭 날짜 기간별 숨김 설정

### 요구사항 정리
- 매월 특정 일 범위(예: 29~31일) 동안 🏆 마일리지 탭을 멤버에게 숨김
- 클럽 설정에서 **부방장(vice-manager) 이상**만 설정 가능
- 현재 마일리지 설정 메뉴(ClubMileageSettings)가 이미 `isClubAdmin`(manager + vice-manager) 대상 → 여기에 추가

파일: `src/pages/Club.tsx`

```ts
// 마일리지 탭 숨김 여부 계산
const today = new Date().getDate(); // 1~31
const hideFrom = selectedClub?.mileage_hide_from_day;
const hideTo = selectedClub?.mileage_hide_to_day;
const isMileageTabHidden =
  !!hideFrom && !!hideTo && today >= hideFrom && today <= hideTo;
```

- 탭 버튼: `isMileageTabHidden` 이면 마일리지 탭 버튼 숨김 (비관리자 기준)

- `activeTab === 'ranking' && isMileageTabHidden && !isClubAdmin` → 자동으로 `'feed'`로 전환 (useEffect)
