# 웹앱 작업지시서 (D:\dev\cardio)
## 목적
Android 앱이 WebView로 이 웹앱을 보여주는 구조로 전환.
Android 앱은 https://cardio.scnd.kr 을 WebView로 띄우며, 두 가지가 필요함.
1. Android WebView 환경일 때 웹앱 자체 바텀 네비 / 헤더 숨기기
2. Android 앱이 보유한 Supabase 세션을 웹앱에 주입하는 브릿지 라우트

---

## 작업 1: 네이티브 앱 감지 훅

### 파일 신규 생성: `src/hooks/useIsNativeApp.ts`

```typescript
export function useIsNativeApp(): boolean {
  return navigator.userAgent.includes('cardio-android');
}
```

Android WebView에서 요청할 때 User-Agent에 `cardio-android` 문자열이 포함됨.
이 훅이 `true`이면 웹앱은 "Android 앱 내부에서 실행 중"으로 판단.

---

## 작업 2: 네이티브 앱 환경에서 Header / BottomNav 숨기기

### 파일 수정: `src/App.tsx`

**현재 코드 (App.tsx, ProtectedRoutes 함수 내부, 약 64~159줄):**
```tsx
return (
  <>
    <Header />
    <div className="main-content">
      <Routes>
        ...
      </Routes>
    </div>
    <BottomNav />
  </>
);
```

**변경 후:**
```tsx
import { useIsNativeApp } from './hooks/useIsNativeApp';

// ProtectedRoutes 함수 내부 상단에 추가
const isNativeApp = useIsNativeApp();

return (
  <>
    {!isNativeApp && <Header />}
    <div className="main-content">
      <Routes>
        ...
      </Routes>
    </div>
    {!isNativeApp && <BottomNav />}
  </>
);
```

네이티브 앱에서는 Header와 BottomNav 둘 다 숨김.
Android 앱이 자체 바텀 네비를 갖고 있으므로 이중 표시 방지.

## 작업 3: 세션 브릿지 라우트

Android 앱이 로그인 후 Supabase 토큰을 웹앱에 전달하기 위한 브릿지 페이지.
앱은 WebView를 열 때 다음 URL로 먼저 이동시킴:
```
https://cardio.scnd.kr/app-auth?token=ACCESS_TOKEN&refresh=REFRESH_TOKEN&redirect=/
```
웹앱이 이 토큰을 받아 Supabase 세션으로 등록한 뒤 원래 목적 페이지로 이동.

### 파일 신규 생성: `src/pages/AppAuthBridge.tsx`

```tsx
import { useEffect } from 'react';
import { useNavigate, useSearchParams } from 'react-router-dom';
import { supabase } from '../lib/supabase';

export function AppAuthBridge() {
  const [params] = useSearchParams();
  const navigate = useNavigate();

  useEffect(() => {
    const token = params.get('token');
    const refresh = params.get('refresh');
    const redirect = params.get('redirect') || '/';

    if (!token || !refresh) {
      navigate('/', { replace: true });
      return;
    }

    supabase.auth.setSession({
      access_token: token,
      refresh_token: refresh,
    }).then(({ error }) => {
      if (error) {
        console.error('앱 세션 주입 실패:', error);
      }
      navigate(redirect, { replace: true });
    });
  }, []);

  return (
    <div style={{ display: 'flex', justifyContent: 'center', alignItems: 'center', height: '100vh' }}>
      <div>로그인 중...</div>
    </div>
  );
}
```

### 파일 수정: `src/App.tsx`

import 추가:
```tsx
import { AppAuthBridge } from './pages/AppAuthBridge';
```

Public routes 블록에 라우트 추가 (기존 `/auth/callback` 근처):
```tsx
<Route path="/app-auth" element={<AppAuthBridge />} />
```

이 라우트는 인증 없이 접근 가능해야 하므로 반드시 `ProtectedRoutes` 밖, Public routes 블록에 추가.

## 작업 4: 네이티브 앱 환경에서 safe area 여백 조정 (선택)

Android 앱의 상단 상태바, 하단 홈 인디케이터와 겹칠 수 있음.
필요시 CSS에서 네이티브 앱 Body에 padding 조정:

```css
/* App.css 또는 index.css */
body.is-native-app {
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
}
```

`App.tsx`에서 `useIsNativeApp()`이 true일 때 `document.body.classList.add('is-native-app')` 처리.
실제로 Android 앱과 맞춰보면서 필요하면 적용.
