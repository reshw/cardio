✨ 새 기능

클럽 단기 챌린지 시스템

클럽 페이지에 챌린지 섹션이 추가됐습니다. 클럽 매니저가 기간을 정해 챌린지를 개설하면, 멤버들이 목표 종목과 목표량을 선언하고 함께 달성해 나갈 수 있습니다.

  • 챌린지 생성 시 허용 종목을 전체 또는 직접 선택
  • 참여 선언: 종목별로 목표 누적량 직접 설정 (다종목 동시 선언 가능)
  • 진행 중 내 달성률 실시간 확인 (진행바 표시)
  • 참여자 전체 현황 및 이름 검색 제공
  • 챌린지별 기간 마일리지 통계 조회 — 엑셀·이미지 다운로드 지원

챌린지 — 시작 전 사전 참여 선언

시작일이 미래인 챌린지도 목록에 표시됩니다. 시작 전에 미리 종목·목표를 선언해두고 D-day를 기다릴 수 있습니다.

  • 기간 표시: YYYY.MM.DD ~ YYYY.MM.DD (N일간)
  • 시작 전 챌린지에 D-N 시작 예정 배지 표시
  • 참여 선언 완료 시 "참여 선언 완료 · N개 종목" 안내

기록 탭 — 이동 거리 마일스톤

기록 탭 통계의 종목별 거리 게이지 아래에 서울→부산 마일스톤 진행률이 추가됐습니다.

  • 달리기, 사이클뿐 아니라 수영도 거리(m→km 환산)에 반영
  • 서울→수원(15km) / 천안(90km) / 대전(140km) / 대구(240km) / 부산(400km) / 한반도 종단(700km) 구간 달성률 표시
  • 이미 통과한 구간은 초록색으로 표시
  • 레이블 "달린 거리" → "이동 거리"로 변경

운동 기록 — 메모 기능

운동 기록 저장 시 메모를 남길 수 있습니다. 피드 카드와 운동 상세 페이지에서 확인 가능하며, 피드에서 메모 탭을 눌러 해당 기록으로 바로 진입할 수 있습니다.

🔧 기능 개선

챌린지 UI — 바텀시트 스타일

챌린지 생성·참여 모달이 화면 하단에서 슬라이드업 되는 바텀시트 형태로 개선됐습니다. 종목 선택 시 기본운동은 항상 펼쳐지고, 기타운동은 접힘/펼침으로 구분됩니다.

클럽 마일리지 — Supabase 대용량 데이터 안정성 개선

클럽 멤버가 많을 때 마일리지 데이터 조회가 누락되던 문제를 개선했습니다. 1,000행 단위 페이지네이션으로 전체 데이터를 안정적으로 불러옵니다.

클럽 닉네임 표시 개선

참여자 목록, 챌린지 현황 등 클럽 내 모든 화면에서 클럽 닉네임이 우선 표시됩니다. 클럽 닉네임이 없는 경우 앱 닉네임을 표시합니다.

운동 상세 바텀시트 개선

운동 상세 페이지가 바텀시트 형태로 개선되어 더 자연스럽게 열리고 닫힙니다.

🐛 버그 수정

운동 기록 저장 시 메모 누락 버그

운동을 처음 저장할 때 메모가 누락되는 오류를 수정했습니다.

챌린지 참여자 조회 오류

챌린지 참여자 목록이 간헐적으로 불러와지지 않던 오류를 수정했습니다.

클럽 마일리지 계산 오류

특정 상황에서 마일리지 계산 함수가 정의되지 않아 오류가 발생하던 문제를 수정했습니다.

불편한 점이 있으시면 더보기 → 수정 요청 / 버그 제보로 알려주세요. 감사합니다!
