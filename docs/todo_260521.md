### 버그 원인 상세
React 18 StrictMode는 side effect 감지를 위해 state updater 함수를 개발 환경에서 2회 호출함.
`setSelectedMonth(prev => { setSelectedYear(y => y+1); return 0; })` 패턴에서
`setSelectedYear`가 2번 호출되어 연도 +2 발생.
→ updater 밖에서 직접 계산 후 두 setter를 독립 호출하는 방식으로 수정.
