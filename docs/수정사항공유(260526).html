🔧 기능 개선

[클럽] 마일리지 탭 개편 — 내순위 / 전체 분리

기존 마일리지 목록이 내순위와 전체 두 탭으로 나뉩니다.
클럽 내 순위도 즐거운 요소이지만, "나"를 위한 운동기록에 좀 더 집중하는 방향으로 조정했습니다.

  • 내순위 탭: 나를 중심으로 위아래 3명씩 표시. 전체 몇 명 중 몇 위인지 바로 확인
  • 전체 탭: 전체 랭킹 목록. 20명 초과 시 접기/펼치기 제공
    • 명전 제외 등 추후 필터링 기능 제공 예정. (추후 신규 제도 대비)
  • 멤버 검색 후 해당 멤버 주변 자동 포커스

[클럽] 명예의 전당 — 하단 카드로 분리

  • 명예의 전당 멤버가 별도 탭으로 표시되던 방식에서, 랭킹 하단 별도 카드로 분리됐습니다.
  • 명예의 전당 카드는 펼치기/접기로 편하게 확인
