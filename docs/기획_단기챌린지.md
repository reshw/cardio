# 클럽 단기 챌린지 기획 검토

> 작성일: 2026-04-28
> 배경: 멀티테넌트 중 특정 클럽장의 요청 — 단기간 챌린지를 클럽원들에게 만들어 주고 싶다

---

## 1. 현재 상태 (AS-IS)

- `challenges` 테이블 + `challengeService.ts` + `ChallengeCard.tsx` 구현 완료
- **하지만 실제 화면(페이지)에 미통합** — 아직 UI에서 접근 불가 상태
- 지원 메트릭: `total_workouts`, `total_distance`, `total_duration`, `total_volume`, `custom`
- scope: `global`(전체 앱) / `club`(클럽 한정)
- progress 계산: 클럽 전체 집계 OR 개인별 집계 모두 지원 중

---

## 2. 클럽장이 원하는 것 (요구사항 추정)

- 클럽장이 **직접 챌린지를 만들고** 클럽원들에게 공개
- 단기간(1일 ~ 2주 내외) 집중 챌린지
- 클럽원들이 참여해서 **누가 얼마나 달성했는지** 볼 수 있어야 함
- 동기부여 요소가 있어야 함 (마일리지 보상? 랭킹?)

---

## 3. 논의할 설계 포인트

### 3-1. 챌린지 단위: 개인전 vs 단체전

| 구분 | 개인전 | 단체전 |
|---|---|---|
| 목표 | 개인 목표치 달성 | 클럽 전체 합산 목표 |
| 보상 | 달성자 개별 수여 | 클럽 전체 달성/실패 |
| 경쟁 | 클럽원 간 랭킹 가능 | 협력 구조 |
| 구현 | progress를 userId 기반으로 | 현재 calcProgress 그대로 |

> **현재 서비스는 두 방식 모두 지원 가능** (userId 유무로 분기)
> 어느 쪽을 먼저 만들까?

---

### 3-2. 기간 단위 선택지

- 1일 (오늘 하루 집중)
- 3일
- 1주 (7일)
- 2주 (14일)
- 커스텀 (직접 날짜 입력)

> 클럽장 UX: 날짜 직접 입력 or 기간 버튼 선택?

---

### 3-3. 달성 보상

| 아이디어 | 구현 난이도 | 효과 |
|---|---|---|
| 보상 없음 (순수 동기부여) | ★☆☆ | 낮음 |
| 마일리지 추가 지급 | ★★☆ | 중간 — 마일리지 시스템과 연동 필요 |
| 뱃지/칭호 | ★★★ | 높음 — 별도 뱃지 시스템 필요 |

> 마일리지 연동이 가장 현실적. 챌린지 달성 시 `mileage_logs`에 보너스 삽입.

---

### 3-4. 랭킹 기능

- 챌린지 기간 내 클럽원별 progress를 내림차순 정렬
- `calcProgress(challenge, clubId, userId)` 를 클럽원 전체에 병렬 호출하면 구현 가능
- **문제:** N명 × 1 DB쿼리 → N+1 문제 발생 가능성
  - 해결안: 챌린지 기간 내 workouts를 한 번에 가져와서 클라이언트에서 집계

---

### 3-5. 알림/노출 방식

- 클럽 홈 화면 상단에 진행 중 챌린지 배너
- 챌린지 탭 별도 신설
- 피드에 챌린지 달성 이벤트 노출

---

## 4. 미결 사항 (결정 필요)

1. **개인전 / 단체전** — 어느 쪽이 이번 요청의 본질?
2. **마일리지 보상 연동 여부** — 클럽별 마일리지에 보너스 가산?
3. **랭킹 공개 방식** — 클럽원 전체 공개? 상위 N명만?
4. **챌린지 생성 제한** — 동시에 몇 개까지? (현재 제한 없음)
5. **UI 진입점** — 챌린지 전용 탭 vs 클럽 홈 섹션 중 어디에?

---

## 5. 빠르게 만들 수 있는 MVP 범위

> 기존 서비스 코드 최대한 재활용, 최소 구현

1. **클럽 홈에 챌린지 섹션 추가** — 진행 중 챌린지 1~3개 노출 (ChallengeCard 사용)
2. **클럽장 전용 "챌린지 만들기" 버튼** — 제목/메트릭/기간/목표값 입력
3. **개인 progress 표시** — 내 달성률 + 클럽 전체 달성률 (두 줄 표시)
4. **만료 자동 처리** — end_date 지난 챌린지는 completed 처리 (배치 or 조회 시점)

> 보상/랭킹/뱃지는 2차로 미룸

---

## 6. 향후 확장 아이디어

- **시즌 챌린지**: 매달 자동 갱신되는 정기 챌린지
- **챌린지 템플릿**: 클럽장이 자주 쓰는 챌린지 저장/재사용
- **클럽간 챌린지**: 다른 클럽과 경쟁
- **퀘스트형**: 단일 목표가 아닌 단계별 미션 (500km → 1000km → 2000km)
