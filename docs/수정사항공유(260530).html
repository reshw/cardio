업데이트 안내 (2026.05.30)

안녕하세요! 주요 업데이트 내용을 안내드립니다.

✨ 새 기능

Strava 연동 — 운동 인증 이미지 자동 생성

Strava에서 운동이 동기화되면 인증 이미지(WebP)가 자동으로 만들어져 첨부됩니다.
별도로 스크린샷을 찍거나 업로드할 필요 없이, Strava 기록이 곧 인증 사진이 됩니다.

  • 실외 달리기 / 사이클 / 오픈워터 — GPS 경로 지도 + 페이스·심박수 정보가 담긴 카드
  • 수영 / 트레드밀 / 실내 — 거리·시간·심박수 위주의 깔끔한 카드

카드 하단에 Recorded by Strava 문구와 기록 기기명이 표시됩니다.

Strava 연동 — 상세 지표 자동 저장

Strava에서 운동이 동기화될 때 거리/시간뿐 아니라 아래 지표도 함께 저장됩니다.

  • 이동 시간 (실제 운동한 시간, 정지 구간 제외)
  • 평균 속도 / 평균 페이스 (달리기·사이클·수영 등 종목별 단위 자동 적용)
  • 평균 심박수

운동 카드를 탭해서 상세 보기를 열면 Strava 데이터 섹션에서 확인할 수 있습니다.

🔧 기능 개선

Strava 운동 시간 오류 수정

Strava에서 넘어오는 운동 시작 시간이 UTC 기준으로 올바르게 저장되도록 수정했습니다.
기존에는 한국 시간(KST)이 UTC로 잘못 해석되어 9시간 차이가 발생하는 문제가 있었습니다.

운동 수정 UX 개선

운동 상세 보기에서 수정 버튼을 누르면 기존 기록이 그대로 채워진 입력 화면으로 이동합니다.
수정 후 저장하면 자동으로 이전 화면으로 돌아갑니다.

기록 목록 Strava 아이콘 위치 변경

기록 목록에서 Strava 아이콘이 날짜 바로 왼쪽에 표시되도록 위치를 조정했습니다.

Strava 기록 기기명 저장

Strava 연동 시 기록 기기(예: Garmin fēnix 8) 정보가 함께 저장됩니다.
운동 상세 보기 → Strava 데이터 섹션에서 확인할 수 있습니다.

피드 카드 UI 간소화

오늘의 운동 피드 카드에 표시되던 Strava 아이콘을 제거했습니다.
Strava 아이콘은 운동 카드 상세 보기에서만 확인할 수 있습니다.

Strava 연동 운동 타입 확장

기존 달리기·사이클·수영 외에 아래 종목이 추가됐습니다.

  • 전기자전거 (EBike)
  • 로잉 / 실내로잉
  • 요가
  • 오픈워터수영

수영 세부 종목 분리

Strava 수영 연동 시 풀수영과 오픈워터로 자동 구분되어 기록됩니다.

불편한 점이 있으시면 더보기 → 수정 요청 / 버그 제보로 알려주세요. 감사합니다!
