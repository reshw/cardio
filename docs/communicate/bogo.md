📋 Claude Code 작업지시서 (Prompt)
[Context & Objective]
현재 개발 중인 사내 러닝 동호회 관리용 웹/앱 'Cardio'의 프로토타입을 회사 부사장님(본부장)께 3분 내외로 대면 소개하려 합니다. 부사장님은 50대 후반 임원으로, 복잡한 코드나 텍스트보다는 '트렌디하고 직관적인 대시보드 화면 한 장'에 쉽게 설득되는 성향입니다.

부사장님 시연용으로 가장 임팩트 있는 [데모 전용 대시보드 메인 화면]을 React(Next.js/Vite + Tailwind CSS 기반)로 신속하게 구현해 주세요.

[Core Value & Philosophy of Cardio]

No Hard Training: 무작정 빨리 달리는 경쟁이 아닌, 안전한 페이스(심박수 Zone 2)와 부상 방지를 위한 효율적인 케이던스(180 목표) 중심의 지속 가능한 러닝 추구.

Data-Driven Motivation: 임직원들의 개인 러닝 마일리지(Mileage)를 정량적 데이터로 시각화하여 재미와 동기부여 제공.

Transparency: 예산 집행이 투명하게 관리되고 참여율이 정량적으로 집계됨을 증명하는 HR 친화적 시스템.

[Required UI Components for Demo]
부사장님이 폰이나 태블릿 화면으로 보았을 때 "와, 우리 직원이 이런 걸 만들었어?" 소리가 나오도록 아래 컴포넌트들을 한 화면에 대시보드 형태로 배치해 주세요. 가상 데이터(Mock Data)를 풍부하게 넣어 살아있는 앱처럼 보이게 합니다.

상단 요약 위젯 (Total Stats):

이번 달 전사 총 러닝 거리 (예: "우미 임직원 이번 달 누적 452km 주행")

활성 멤버 수 및 총 소모 칼로리

사내 실시간 리더보드 (Leaderboard):

부서 간 벽을 허무는 네트워킹을 시각화하기 위해 [이름 / 부서 / 이번 달 누적 거리(km) / 평균 케이던스]가 깔끔하게 순위별로 정렬된 컴포넌트 (예: 1위 양 과장 - 복합사업팀, 2위 김 대리 - 경영지원팀...)

안전 러닝 스크리닝 (Zone 2 & Cadence Chart):

간단한 차트(가급적 Recharts 활용)나 시각적 인디케이터를 통해 멤버들이 안전 영역(Zone 2 심박수, 케이던스 180 근접도)에서 얼마나 건강하게 달리고 있는지 보여주는 지표.

모바일 최적화 (Responsive UI):

부사장님실에서 스마트폰으로 슥 보여드리기 가장 좋으므로, 모바일 세로 화면(Mobile-first)에서 완벽하고 트렌디하게 떨어지는 UI. (Dark Mode 우대, Garmin 인터페이스 느낌의 스포티하고 고급스러운 톤앤매너)

[Output]
위 기획 의도를 완벽히 반영하여 즉시 화면을 띄워 볼 수 있는 Clean Code를 작성해 주세요. 임원진이 직관적으로 이해할 수 있는 '직장인 웰니스 플랫폼'의 느낌이 나야 합니다.
