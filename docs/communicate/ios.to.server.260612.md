# 서버 요청 — workout_types 테이블 걷기 항목 추가

## 요청 내용

`workout_types` 테이블에 **걷기** 카테고리 추가 부탁드립니다.

| 컬럼 | 값 |
|------|----|
| category | 걷기 |
| unit | km |
| 적립 여부 | 미적립 (포인트/랭킹 산정 제외) |

## 배경

- Apple Health의 `.walking` 타입(출퇴근 등 일상 걷기)이 앱에서 자동 동기화됨
- 운동 기록으로는 올라가되, 클럽 랭킹/포인트 적립에는 제외하고 싶음
- iOS 클라이언트는 빌드 8에서 걷기를 `걷기/km`로 업로드하도록 수정 완료
- Android도 동일하게 반영 예정

## 요청 순서

1. 서버 `workout_types` 에 걷기 추가 (미적립 플래그)
2. iOS 빌드 8 배포
3. Android 클라이언트 반영
