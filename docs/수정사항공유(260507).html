통계 탭 — 지난달 페이스 비교

기존에는 이번 달 누적값을 지난달 전체 합산과 단순 비교해, 월 중반에 보면 항상 지난달보다 적게 나오는 문제가 있었습니다. 이를 페이스 기준 비교로 전면 개편했습니다.

  • 기준값: 지난달 하루 평균 × 이번 달 경과 일수
  • 예) 지난달 달리기 150km (30일) → 하루 평균 5km. 오늘 15일차라면 기준 75km. 현재 80km면 ▲ 107% 표시
  • 과거 월 조회 시에도 동일 공식 적용 (해당 월 전체 일수 기준)
  • 종목별 거리 게이지의 기준선도 페이스 기준으로 변경
  • 비교 카드 옆 ⓘ 버튼을 누르면 계산 방식과 실제 수치 예시를 확인할 수 있습니다

🐛 버그 수정

세로 사진이 가로로 저장되는 이슈

일부 기기에서 운동 기록에 세로 사진을 첨부하면 가로로 저장되는 문제를 수정했습니다.

  • 원인: 이미지 변환 서버가 JPEG에 포함된 방향(EXIF Orientation) 정보를 무시하고 저장
  • 수정: 이미지 저장 전 EXIF 방향 정보를 읽어 픽셀을 올바르게 회전한 뒤 저장하도록 처리
  • 원본 이미지 및 썸네일 모두 적용
  • 기존에 잘못 저장된 이미지는 소급 적용되지 않습니다. 새로 업로드하는 이미지부터 정상 저장됩니다.
