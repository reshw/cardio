수동 입력 여부

manual 필드로 구분 가능. Strava 앱에서 직접 수동 입력한 활동은 manual: true, 기기(Garmin, Apple Watch 등)에서 자동 연동된 활동은 manual: false.
필드예시 값설명
manualfalse수동 입력 여부 미사용 — true면 기기 없이 직접 입력한 기록
trainertrue실내 트레이너(롤러 등) 사용 여부 미사용
commutefalse출퇴근 이동 여부 불필요
flaggedfalseStrava에서 의심 활동으로 플래그 처리 여부 불필요

시간

필드예시 값설명
start_date"2026-05-30T05:08:10Z"시작 시간 (UTC) 사용 중 — workout_time으로 저장
start_date_local"2026-05-30T14:08:10Z"로컬 시간 (Z가 붙지만 UTC 아님 — 주의!) 사용 안 함 — timezone 없이 쓰면 9시간 오차 발생
timezone"(GMT+09:00) Asia/Chita"기록된 시간대 미사용
utc_offset32400.0UTC 오프셋 (초 단위, 32400 = +9시간) 미사용
elapsed_time1812총 경과 시간 (초) — 정지 포함 사용 중 — elapsed_seconds로 저장
moving_time956실제 이동 시간 (초) — 정지 제외 사용 중 — moving_seconds로 저장
